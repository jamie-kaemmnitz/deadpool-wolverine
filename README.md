Deadpool & Wolverine movie reviw
=================================================================
Project description
-------------------
My first project i created, this is a basic webpage reviewing the movie i had recently seen.

The project is based on a single html file, there is an introduction to the page and what its about, then a short section about the movie with a brief run through of the story. There is a cast section with anchor links to the wikipedia pages for a number of the main cast in the film.
I have included a small piece of JavaScript in the cameo section, there us a button which can be clicked to open up a list of images of cameos that appear in the film, this can be closed back down by reclicking the button. The button is originally a logo from the movie but once clicked it turns into an image of a shocked looking Deadpool.
Finally i leave my final review at the bottom of the page. 

There is an image background of Deadpool and Wolverine covering the entire page, i have used colours from the movie for text colour and also included background around texts for better readability.

The entire webpage was created using HTML CSS and Javascript.

How to Install and Run
----------------------
You cabn download the code by clicking the green code button and copying the link in the box. You can also run the webpage by entering the following link into your browser - https://jamie-kaemmnitz.github.io/deadpool-wolverine/
